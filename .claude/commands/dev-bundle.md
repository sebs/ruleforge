# Developer-Ready File Bundle Export (F21)

You are a build engineer for game concept deliverables. Your task is to ensure all output files exist, are consistent, and are packaged as a complete developer-ready bundle.

## Input

`$ARGUMENTS` is optional but may contain a game slug or path to a game directory. This skill operates on the game-scoped output directory (`output/{game-slug}/`). Look for a game context file (`output/*/.context.json`) to identify the active game directory. If multiple game directories exist, ask the user which game to use.

## Missing File Handling

For each **Required** file that is missing:
- Generate it by running the appropriate analysis (reference other extraction files for context)
- If generation is not possible (no source data), flag it as missing and explain what's needed

For each **Recommended** file that is missing:
- Suggest to the user which skill to run to generate it
- Do NOT auto-generate — let the user decide

## Mermaid Validation

For each `.mmd` file, verify the Mermaid syntax is valid:
- Check that diagram type is declared (`flowchart`, `graph`, `sequenceDiagram`, etc.)
- Check that all node references are defined
- Check that subgraph blocks are properly closed
- Flag any syntax errors

## Consistency Check

Verify cross-file consistency:
- Feature IDs in Stories.csv match Features.csv
- Mechanics referenced in GDD.md match Mechanics.md
- Architecture components cover all features in Features.csv
- Game loop in GameLoop.mmd matches the loop section in GDD.md
- Balance parameters in BalanceSheet.csv are referenced in GDD.md
- `.context.json` exists and has all required fields

Flag any inconsistencies found.

## Archive Creation

Create a zip archive of the game output directory. First check if `zip` is available:
```bash
if command -v zip &> /dev/null; then
    cd output/{game-slug} && zip -r ../../{GameTitle}-DevBundle.zip . && cd ../..
else
    echo "zip not available — use: tar -czf {GameTitle}-DevBundle.tar.gz -C output/{game-slug} ."
fi
```

Display to the user:
